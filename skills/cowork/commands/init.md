# /cowork:init — 이 프로젝트의 cowork 시스템 프롬프트 만들기

`.cowork/cowork-prompt.md` 를 만든다. 이 파일은 이후 **모든 cowork 분석에서 claude·codex·grok·kimi·deepseek·minimax·qwen·agy 여덟 AI 의
프롬프트 맨 앞에 반드시 주입**되는 이 프로젝트의 시스템 프롬프트다. 여기에 프로젝트의 **특성·기획·
계획·아바타(persona)·디자인·로직·개념·용어·금지사항**이 적혀 있을수록 여덟 AI 의 분석 품질이 올라가고,
비어 있으면 여덟 AI 는 프로젝트 목적을 모른 채 일반론으로 답한다.

## 절차

### 1. 뼈대 생성

```bash
bash .claude/skills/cowork/scripts/cowork.sh --init
```

- 파일이 없으면 자동 감지(작업공간 이름·경로·개발 스택·파일 종류 분포·지침 문서·최상위 디렉토리)
  결과가 담긴 초안이 생긴다.
- **이미 있으면 건드리지 않고 그대로 둔다.** 그때는 기존 파일을 읽고 **부족한 절만 보강**하라
  (사람이 쓴 내용을 지우지 말 것). 감지 결과로 완전히 새로 만들어야 할 때만 `--init --force`
  (기존 파일은 `.bak` 로 백업된다).

### 2. 작업공간을 실제로 훑는다 〔이 단계를 생략하지 말 것〕

스크립트는 파일 존재 여부만 안다. **무엇을 하는 프로젝트인지는 네가 읽어서 판단해야 한다.**

- 루트 지침 문서(`README.md`·`CLAUDE.md`·`AGENTS.md` 등)를 읽는다.
- 최상위 디렉토리 구조를 보고, 각 디렉토리의 대표 파일을 몇 개 열어 실제 내용을 확인한다.
- 소프트웨어면 진입점·핵심 모듈·설정 파일을, 문서·교재·레시피류면 대표 산출물 2~3개를 연다.
- 프로젝트 고유의 **용어**와 **불변 규칙**을 찾는다(이게 Instructions 절의 핵심 재료다).

### 3. 네 절을 실제 내용으로 채운다

`.cowork/cowork-prompt.md` 를 편집해 **괄호 안내문을 지우고 진짜 내용으로 교체**한다. 안내문을 그대로
남겨 두면 여덟 AI 에게 안내문이 주입된다.

| 절 | 채울 내용 |
|---|---|
| `## Overview` | 이 프로젝트가 무엇이고 무엇을 만들고 있으며 지금 어느 단계인지. 8 AI 에게 무엇을 시키려는지. 기획 의도·목표·계획 |
| `## Persona` | 여덟 AI 가 맡을 전문가 역할(아바타). 이 분야에 맞는 인격 — 관점 자체가 달라진다 |
| `## Instructions` | 반드시 지킬 규칙·핵심 개념·설계 로직·우선순위·금지사항. 프로젝트 고유 용어 정의 |
| `## Tech stack` | 기술·도구·파일 형식·자료 구조·디자인 규격 (자동 감지 결과를 실제로 확인해 교정) |

- 네 절은 **뼈대**다. 필요하면 절을 더 추가하라 — `## 기획`, `## 용어 정의`, `## 설계 규칙`,
  `## 데이터 구조`, `## 금지사항`, `## 참고 자료` 등.
- **추측으로 채우지 말라.** 확인한 것만 쓰고, 사람이 정해야 할 항목(대상 사용자·품질 기준·마감 등)은
  빈칸 대신 `(사람이 채울 것: …)` 로 남겨 무엇이 필요한지 명시한다.
- 여덟 AI 는 읽기 전용이므로 이 파일에 "파일을 만들어라" 류의 지시를 써도 실행되지 않는다.

### 4. 사용자에게 보고

- 만든 `.cowork/cowork-prompt.md` 의 네 절을 **본문에 요약해 보여준다**(경로만 던지지 말 것).
- 추측으로 채운 부분과 사람이 확정해야 할 항목을 짚어 준다.
- 이후 `/cowork <폴더명> <질문>` 을 쓰면 이 파일이 자동 주입된다고 한 줄 알린다.

## 함께 쓰는 명령

| 명령 | 하는 일 |
|---|---|
| `cowork.sh --init` | **이 명령** — 시스템 프롬프트 `.cowork/cowork-prompt.md` 생성 |
| `cowork.sh --init-hook` | 별개 기능 — final-report 자동 리뷰 라운드 Stop hook 설치 |
| `cowork.sh --list` | 진행 중인 cowork 작업 목록·상태 |

전체 흐름과 규칙은 [../SKILL.md](../SKILL.md) 를 따른다.
